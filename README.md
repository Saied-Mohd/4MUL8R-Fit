# 4MUL8R Fit

Recomp tracker PWA: nutrition logging, meal-slot budgets, training programs, muscle recovery map, and an AI food/workout logger (OpenRouter, bring your own key).

Single-file app (`index.html`) served by GitHub Pages at https://saied-mohd.github.io/4MUL8R-Fit/. Data lives in the browser (localStorage `recomp-*` keys); keep those keys stable.

Formerly "Day Logger".
